The proposed workflow

See the rule before you trust the result.

A team should be able to inspect what the system read, what code it proposed, and what happened when that code ran.

01

Ask for repository access

AuditMind explains the access it needs to prepare a branch and pull request. This demo can continue locally until GitHub is set up.

02

Inspect the sources and code

It finds a shared reference across deposit events, customer credits and ledger entries, then presents a check for your approval.

03

Run, then verify

The preview executes the proposed code. Only afterward does it generate a proof and show the committed row hashes.
